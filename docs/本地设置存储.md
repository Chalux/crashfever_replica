# 本地设置存储

移植 kemo_card 的数据、应用服务、存储服务分层，替换其 .NET 文件读写为 Cocos `sys.localStorage`。当前只保存音频设置，不包含编队或战斗恢复，不改变项目总纲的功能范围。

## 文件职责

- `assets/Scripts/Model/App/Save/SettingsData.ts`：版本 1 数据结构、默认值、深复制、运行时字段校验。保存 master/bgm/sfx/ambient 各自的 `volume`（0～100）和 `muted`。
- `SettingsSaveService.ts`：与引擎无关，通过注入的键值存储读写 JSON，主档失败后尝试备份。
- `SettingsService.ts`：接入 `sys.localStorage`、管理已确认设置、获取试听快照并应用到 `Sound`。
- `AppEntry`：注册 Sound 后初始化设置，在首次播放音频前恢复。
- `SettingDlg`：打开时捕获原值，控件即时试听，保存成功后关闭，取消或未保存关闭时恢复；失败时显示“保存失败”，保留弹窗与试听状态，可重试或取消。

没有新增编辑器字段，现有 Slider、Toggle 绑定继续使用。BGM 等原有测试控件保持现状。

## 存储与恢复

主键 `crashfever.settings`，备份键 `crashfever.settings.backup`。它们与当前应用/浏览器来源的存储空间关联，不是项目目录中的 JSON 文件。

读取只接受版本 1 及完整有效字段；不存在、JSON 损坏、字段非法会尝试备份，再使用独立默认值。读取不会自动写盘。若遇到更高版本或存储访问失败，使用默认值运行，并禁止本次会话保存以保护原数据。修复访问或版本问题后重新启动。

保存先校验新数据；仅将有效的旧主档复制到备份，再写新主档。损坏主档不会覆盖有效备份。存储异常返回失败，不提交内存中的已确认设置。多个键不是事务，不声称与 Godot `File.Replace` 一样原子。第一笔保存尚无旧主档，因此没有历史备份。当前不迁移其他项目的存档，也不存在需要迁移的旧版 Cocos 存档；将来改变格式需显式新增版本迁移，不能直接重写版本号。

## 验证

运行 `npm run test:save`：使用内存存储与音频替身验证默认值、跨实例恢复、备份回退、字段校验、高版本保护、读取/写入失败、试听回滚和启动应用。它不替代 Cocos 实机验证。

编辑器中验证：修改并保存后重启，音量和静音保留；修改后取消，再次打开恢复原值；连续开关无重复订阅。跨平台导入导出、编队、战斗快照在对应阶段实现。
