## 4. 实现

### 4.1 `AppRedDotTree.ts`

保持文件**不 import `cc`**（`npm run test:reddot` 会把它编进核心测试；`cc/env` 也不行）。

```ts
export const appRedDotId = {
    main: 'main',
    team: 'main/team',
    stage: 'main/stage',
    setting: 'main/setting',
    stageOf: (chapterId: string): string => `main/stage/${chapterId}`,
} as const;

/** 仅演示数据；由 AppEntry 在 if (DEV) 下调用一次，接入真实系统后整体删除。 */
export function seedDemoRedDots(): void {
    RedDot.Batch(() => {
        RedDot.Set(appRedDotId.team, 2);
        RedDot.Register(appRedDotId.stageOf('1001'), appRedDotId.stage, 100);
        RedDot.Register(appRedDotId.stageOf('1002'), appRedDotId.stage, 20);
    });
}
```

> 注意：DEV 守卫放在 **AppEntry 的调用处**，不要写进 `seedDemoRedDots()`（否则 `AppRedDotTree.ts` 需要 import `cc/env`，核心测试无法编译）。设计稿 §8 里的写法按这一点调整。

### 4.3 `MainWin.ts`

只追加三个点击处理；`onOpen` 保留为空实现（BaseWin 要求），不要在这里 seed/ClearTree：

```ts
import { RedDot } from '../../../Frame/RedDot';
import { appRedDotId } from '../RedDot/AppRedDotTree';

private _onTeamEditBtnPress(): void {
    // 用户已经进入编队页 → 该入口清零（真实页面按“看到/领取”的粒度清）
    RedDot.ClearTree(appRedDotId.team);
    // ...原有打开 ConfirmDlg 的逻辑不变
}

private _onStageBtnPress(): void {
    RedDot.ClearTree(appRedDotId.stage);   // 关卡入口同理（推荐）
    // ...原有打开逻辑不变
}
```

约定：

- **不要**在 `onOpen` 里 `ClearTree` 或 `seedDemoRedDots`（MainWin 有 30s 缓存，`onOpen` 会重复执行）。
- **不要** `ClearTree(appRedDotId.main)`（会把所有入口一起清掉）。
- 设置入口种子计数为 0（隐藏），本任务可以不清；要清就在处理里 `RedDot.Clear(appRedDotId.setting)`，无副作用。
- 父入口 `main` 目前没有挂角标；父节点变化用控制台 `RedDot.Get('main')` / `RedDot.Snapshot()` 验收。

动态列表演示命令（种子已注册 1001/1002 的前提下）：

```js
// 列表项移除：stage 120 → 20，父 main 120 → 22
RedDot.Unregister('main/stage/1001');

// 新增列表项：stage 20 → 25
RedDot.Register('main/stage/1003', 'main/stage', 5);

// 全量重建：清旧项、注册新项（batch 内只刷新一次）
RedDot.Batch(() => {
  RedDot.Unregister('main/stage/1002');
  RedDot.Unregister('main/stage/1003');
  RedDot.Register('main/stage/2001', 'main/stage', 100);
  RedDot.Register('main/stage/2002', 'main/stage', 20);
});

// 断言：Snapshot 里不能残留 1001/1002/1003；stage=120、main=122
```

## 8. 常见坑

1. 把 `seedDemoRedDots()` 放进 `MainWin.onOpen` → 30s 缓存重开会重播，抵消 `ClearTree`。
2. `ClearTree('main')` → 所有入口一起清零。
3. `AppRedDotTree.ts` import `cc`/`cc/env` → 核心测试编译失败。
4. 列表项 ID 拼错不会报错，只是永远不显示；统一用 `appRedDotId.stageOf()`。
5. `Unregister` 会移除整棵子树；重建父节点时要先重新 `Register` 父节点。
6. 对象池回收但数据项还在时不要 `Unregister`（设计稿 §12-1 的待确认项）。
7. 跨语义入口：编队是“可领取”、关卡是“未读”，不要把它们混到同一个数字父入口；本任务 `main` 不挂角标，不受影响。
8. 列表项要“先挂到激活节点、再设 `RedDotId`”（单节点/回退模式尤其重要）。
