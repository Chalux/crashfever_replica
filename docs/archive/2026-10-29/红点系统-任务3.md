## 3. RedDotBadge 改造要求

### 3.1 视觉结构

```
RedDot (RedDotBadge, UITransform 40×28, Widget TOP|RIGHT)
└─ Visual (UITransform 40×28)          ← 只切 active；Graphics 由组件在 onLoad 时 ensure
   └─ Count (Label, RESIZE_HEIGHT)     ← _countLabel
```

- `RedDotBadge` 不再依赖 `Sprite` 和底图：`onLoad` 里对 `Visual` 节点做
  `visual.getComponent(Graphics) ?? visual.addComponent(Graphics)`。
- `Graphics` 只画一次（尺寸/模式不变就不重复画），`_refresh` 只切 `Visual.active` 和 `Count`。
- 颜色常量：`new Color(230, 48, 48, 255)`（可按视觉再调）。
- 数字模式：`roundRect(-w/2, -h/2, w, h, r)`，`r = min(w/2, h/2, 10)`；`fill()`。
- 圆点模式：`circle(0, 0, min(w, h) / 2)`；`fill()`。
- 尺寸从 `UITransform.contentSize` 取，取不到时默认 40×28。

### 3.2 生命周期与 API

- `onLoad()`：先订阅 `RedDot.OnChanged`，再置 `_loaded = true`，然后 `_draw()` + 一次 `_refresh()`（防御 `redDotId` 在 `onLoad` 前被赋值/序列化）。
- `onEnable()`：`_refresh()`（缓存重开/隐藏再显示时补快照，不重新订阅）。
- `onDestroy()`：`this._binder.unbindAll()`。
- `setter RedDotId`：同值直接 return；`_loaded` 为 true 才 `_refresh()`。
- 补 `public get BinderCount(): number { return this._binder.count; }`（任务 3 验收硬性项）。
- 日志统一 `Log.error(msg, 'RedDot')`，不要 `import { LogOptions }` 当值用。

### 3.3 代码骨架

```ts
import { _decorator, Color, Component, Graphics, Label, Node, Size, UITransform } from 'cc';
import { Log } from '../Log';
import { BindingScope } from '../UI';
import { RedDot } from './RedDot';
import { formatRedDotCount } from './RedDotFormat';

const { ccclass, property } = _decorator;
const BADGE_FILL = new Color(230, 48, 48, 255);

@ccclass('RedDotBadge')
export class RedDotBadge extends Component {
    @property({ type: String }) private _redDotId = '';
    @property({ type: Node }) private _visual: Node | null = null;
    @property({ type: Label }) private _countLabel: Label | null = null;
    @property({ type: Boolean }) private _dotOnly = false;
    @property({ type: Number }) private _maxCount = 99;

    private _binder = new BindingScope();
    private _loaded = false;

    public get BinderCount(): number {
        return this._binder.count;
    }

    public get RedDotId(): string {
        return this._redDotId;
    }

    public set RedDotId(value: string) {
        if (this._redDotId === value) return;
        this._redDotId = value;
        if (this._loaded) this._refresh();
    }

    protected onLoad(): void {
        this._binder.add(RedDot.OnChanged((change) => {
            if (change.ids.has(this._redDotId)) this._refresh();
        }));
        this._loaded = true;
        this._draw();
        this._refresh();
    }

    protected onEnable(): void {
        this._refresh();
    }

    protected onDestroy(): void {
        this._binder.unbindAll();
    }

    private get visualNode(): Node {
        // 回退：_visual 留空时直接切组件节点自身（需要 _loaded 守卫）
        return this._visual ?? this.node;
    }

    private _draw(): void {
        const visual = this.visualNode;
        const transform = visual.getComponent(UITransform);
        const size = transform ? transform.contentSize : new Size(40, 28);
        const graphics = visual.getComponent(Graphics) ?? visual.addComponent(Graphics);

        graphics.clear();
        graphics.fillColor = BADGE_FILL;
        if (this._dotOnly) {
            graphics.circle(0, 0, Math.min(size.width, size.height) / 2);
        } else {
            const radius = Math.min(size.width / 2, size.height / 2, 10);
            graphics.roundRect(-size.width / 2, -size.height / 2, size.width, size.height, radius);
        }
        graphics.fill();
    }

    private _refresh(): void {
        const id = this._redDotId;
        const total = id ? RedDot.Get(id) : 0;
        const visible = total > 0;

        const visual = this.visualNode;
        if (visual.active !== visible) visual.active = visible;
        if (!visible) return;

        if (this._countLabel) {
            this._countLabel.node.active = !this._dotOnly;
            if (!this._dotOnly) {
                this._countLabel.string = formatRedDotCount(total, this._maxCount);
            }
        }
    }
}
```

### 3.4 回退模式（`_visual` 留空）的守卫

- `onLoad` 之前 setter 只记录 ID，不操作节点；避免“首次激活前把自己隐藏 → `onLoad` 不执行 → 永久不订阅”。
- 回退模式下隐藏的是组件节点自身；`RedDot` 的订阅常驻，后续计数变大时事件回调里会重新 `active = true`，因此能恢复。
- 列表项（任务 4）实例化时仍然要求：**先挂到激活节点、再设 `RedDotId`**。
- 运行时不要手动改 `this.node.active`，只让 `_refresh` 控制。

### 4.1 节点结构（数字模式）

```
TeamButton (Button, UITransform 280×86)
└─ RedDot (RedDotBadge, UITransform 40×28, Widget)   ← 按钮的直接子节点、最后一个子节点
   └─ Visual (UITransform 40×28)                     ← 不做 Sprite，Graphics 运行时加
      └─ Count (Label 字号20, 白色, outline, RESIZE_HEIGHT)
```

- `RedDot` 节点默认 `active=true`；不要挂 `Button` / `BlockInputEvents` / 触摸监听。
- `Visual` 默认 `active=true`；运行时由 `_refresh` 切。
- `Count` 宽度约 36、高 24、`_overflow=3`（RESIZE_HEIGHT）、`_enableWrapText=False`。
- 设置入口：`RedDot` 必须是 `SettingButton` 的直接子节点，**不能放进带 `cc.Mask` 的 `IconViewport`**；放在 `SettingsText` 之后，保证画在图标/文字之上。

### 4.3 新增 badge helper

```python
def badge(self, parent, red_dot_id, dot_only=False, max_count=99):
    red_dot = self.node('RedDot', parent, 40, 28)
    self.comp(red_dot, 'cc.Widget', _alignFlags=33, _alignMode=2, _target=None,
              _top=-4, _right=-4, _left=0, _bottom=0,
              _horizontalCenter=0, _verticalCenter=0,
              _isAbsTop=True, _isAbsRight=True)
    visual = self.node('Visual', red_dot, 40, 28)
    count, label = self.label('Count', visual, '99+', 36, 24, size=20,
                              tint=color(255, 255, 255), outline=True)
    self.items[label].update(_overflow=3, _enableWrapText=False)
    self.custom(red_dot, 'RedDotBadge', _redDotId=red_dot_id, _visual=ref(visual),
                _countLabel=ref(label), _dotOnly=dot_only, _maxCount=max_count)
    return red_dot
```

说明：

- `_alignFlags=33` = TOP(1) | RIGHT(32)；`_alignMode=2` = `ALWAYS`。
- `top=-4` / `right=-4` 让角标略微压出按钮右上边缘（就是第 5 条说的“贴右上角”）。
- `dot_only=True` 时只画圆形并隐藏 `Count`；MainWin 三个入口先用数字模式，圆点变体验收时可临时生成一个（见 §6 第 7 项）。

## 8. 常见坑

1. 手改 `MainWin.prefab` 会被重跑生成脚本覆盖；必须改 `build-app-ui.py`。
2. 红点挂进带 `cc.Mask` 的容器（如 `SettingButton/IconViewport`）会被裁剪。
3. `RedDot` 组件节点初始 `inactive` 会导致 `onLoad` 不执行、永不订阅。
4. 回退模式下 `onLoad` 前不能隐藏组件节点，否则永久失聪；这就是 `_loaded` 守卫存在的原因。
5. 角标底图是 Sprite 贴图：圆形用 `SIMPLE` 渲染，不要再改回 `FILLED/RADIAL`。
6. Widget 当前 `top/right = 0`（贴在按钮内沿）；要压出边缘就改负值，并确认不压到图标/文字。
7. `Count` 用 `Overflow.NONE`，文本不会被裁剪；改字号/宽度后要重新确认 `99+` 没有压出圆底。
8. prefab 里序列化的 `_redDotId` 不走 setter；运行时改 ID 请走 `RedDotId` setter。
9. 角标上不要加 `Button` / `BlockInputEvents` / 触摸监听，否则挡点击。
10. 三个入口 ID 必须与 `AppRedDotTree.ts` 一致（`main/team`、`main/stage`、`main/setting`）；拼错不会报错，只会一直不显示。
