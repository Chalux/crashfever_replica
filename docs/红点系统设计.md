# 红点系统当前契约

更新：2026-10-29。此文件替代带有多轮覆盖说明的旧设计与任务指引。旧稿和评审证据见[归档](archive/2026-10-29/README.md)。

## 数据和接口

实现位于 `assets/Scripts/Frame/RedDot/`。核心不依赖 `cc`，`index.ts` 不导出引擎组件 `RedDotBadge`。

- 父子关系显式注册，不通过 ID 路径推断。`total = own + 所有直接子节点 total`。
- Store 与静态门面公开接口：`Register/Unregister/Set/Add/Clear/ClearTree/Get/GetOwn/Has/IsRegistered/Batch/OnChanged/Snapshot/ResetCounts/Dispose`；门面另有 `Initialize`。
- 计数归一为非负整数，非有限值按零。`Add` 先将有限 delta 与 own 相加，再归一，保留负数/小数语义。
- 快照为独立副本，类型 `IRedDotNodeInfo`，字段 `id/parent/own/total`。
- `Batch` 同步改数据、合并通知，可嵌套；异常时发送已累积变化并透传异常，不回滚。
- 事件 `reddot.changed` 携带脏 ID 快照。监听器异常隔离，重入排入下一轮；单次 flush 最多 100 轮，达到上限记录错误、保留待发变化到下次写入。
- 门面 `Initialize` 幂等；`Dispose` 清 Store 和转发，但保留 dispatcher 上现存视图监听，重建 Store 后仍可通知。视图销毁必须自行退订。

## 角标和接线

- `RedDotBadge` 在 `onLoad` 订阅，`onEnable` 补刷新，`onDestroy` 退订；`BinderCount` 用于检查订阅数。
- 0 隐藏，默认最大显示 `99+`；圆点模式隐藏文字。Sprite 承载视觉，数字 Label 使用 Overflow.NONE。
- 默认只切 `Visual.active`；允许回退组件节点自身。`onLoad` 前设置 ID 仅记录，防止提前隐藏导致不加载。动态列表项先挂到激活节点，再设置 ID。
- `RedDotBadge.prefab` 与 `RedDotBadgeDotOnly.prefab` 分别提供数字和圆点变体；主页三个入口通过嵌套 prefab 引用。
- AppEntry 初始化并注册 `main`、`main/team`、`main/stage`、`main/setting`；仅 DEV 调用演示种子。编队 2、关卡子项合计 120、设置 0。
- MainWin 点击编队/关卡清对应子树；重开不播种、不清整个 main。真实业务接入后再替换演示来源；不将“可领取”等演示语义当作正式玩法需求。

`npm run test:reddot` 本次 81 项全过；引擎视觉和点击验收边界见[当前实现](当前实现.md)。
