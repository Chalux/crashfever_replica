# 标题进入与恢复检查占位

日期：2026-10-29。状态：待用户实现。启动重试行为检查通过，用户已确认翻译修复正常。

目标：将 `标题点击 → 直接进入主页` 改为 `标题点击 → 检查恢复状态 → 对应分支`。正常版本目前返回无恢复数据；其他分支通过开发替身验收。完成后进入角色配置与编队阶段。

## 分工与文件

用户实现游戏脚本与界面；助手维护测试和审查。不新增正式战斗快照、不改设置存储格式，不实现战斗或关卡页。

| 位置 | 改动 |
| --- | --- |
| 新增 `Model/App/Recovery/` 下的服务/接口 | 无 cc 依赖，提供 none/available/incompatible 检查结果与放弃操作；正常实现返回 none |
| AppEntry | 独立的标题进入方法负责检查、弹窗和导航；提取现有打开主页逻辑 |
| TitleWin | 等待检查/选择结束，防连点；正常留在标题时也能解锁 |
| 语言库、索引、XLSX/CSV | 补恢复提示、继续、放弃、暂未开放及不兼容文案 |

不建立通用路由框架，不预设 battleState 等正式快照字段，不将测试恢复记录写入 SettingsService。

## 分支规则

1. **none**：打开 MainWin 成功后再关闭 TitleWin；打开失败保留标题，允许重试。
2. **available**：提示发现未结束战斗，按钮为“继续战斗 / 放弃战斗”。
   - 继续：当前没有战斗模块，明确显示“战斗功能尚未实现，暂时无法继续”；不删除记录，留在标题并解锁再次点击。
   - 放弃：等待清除成功后进入主页；清除失败依赖 ConfirmDlg 现有失败重试能力，不进入主页，不清设置。
3. **incompatible**：中文提示恢复数据与配置不兼容。总纲最终去向是关卡选择；当前关卡页未实现，确认后进入主页并展示现有“暂无关卡/功能未开放”的占位提示。保留独立的关卡选择入口方法供后续替换，不把主页称作关卡页。本任务不自动删除不兼容记录，真实存档阶段再明确清理策略。

## 实施顺序

1. 提取现有打开主页的方法，先保持正常路径不变。
2. 注入默认 none 的检查服务，标题回调调用独立进入方法。
3. 用开发替身接 available 的两个回调，再接 incompatible。
4. 加入一次进入请求的锁定及失效标记；每次 await 后检查生命周期，旧弹窗回调不得导航。
5. 测试替身验证分支，移除临时注入；正常版本不能固定弹出模拟恢复提示。

## 关键陷阱

`await manager.open('ConfirmDlg', payload)` 只等窗口打开，不等玩家选择。进入流程必须等待选择及对应回调完成，也必须处理弹窗返回 null、抛异常和流程销毁，避免永久挂起。

当前 TitleWin 只在 onEnter 抛异常时释放 `_enterlock`。选择“继续”后会正常留在标题，必须也能释放锁。可让回调返回 entered/stay，或在 finally 中按存活状态释放；正常留在标题不作为异常。检查和等待选择期间仍需防连点。

动态标题、正文、按钮文案由调用代码执行 `l10n.t()` 后传入，不能给相应 Label 添加翻译组件；百分比和红点数字继续直接格式化。BGM 与已通过的加载流程保留。

## 验收

| 场景 | 结果 |
| --- | --- |
| 无记录 | 检查一次；主页打开成功才关闭标题 |
| 有记录 → 继续 | 未开放提示明确；不删记录；标题可再次点击 |
| 有记录 → 放弃 | 清除成功才进主页；失败可重试 |
| 不兼容 | 明确提示与关卡占位去向 |
| 检查/弹窗/主页失败 | 保留标题与重试机会，无未处理异常 |
| 快速连点 | 一次检查、一个弹窗、一次导航 |
| 等待时销毁 | 等待可结束，旧结果与回调不再打开后续窗口 |

用户完成后由助手补进入流程行为回归；现有启动、翻译、导入保留键、确认弹窗、红点和设置检查保持通过。按钮、遮罩与文字布局另在 Cocos 预览验收。
