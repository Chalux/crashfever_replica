# 确认弹窗与原包界面适配

## 使用确认弹窗

路由已在 `AppEntry` 注册，Prefab 位于 `assets/resources/ui/app/ConfirmDlg.prefab`。

```ts
import type { ConfirmPayload } from './ConfirmDlg';

await UIManager.instance.open<ConfirmPayload>('ConfirmDlg', {
    title: '覆盖存档',
    message: '导入会覆盖现有存档，是否继续？',
    confirmText: '导入',
    cancelText: '取消',
    onConfirm: async () => {
        // 在这里执行操作；若失败请抛出异常。
    },
});
```

`open()` 只表示界面打开完成，不是玩家选择的结果。确认与取消通过各自回调返回。正文自动换行，较长内容限制视口高度并允许纵向滚动。回调执行期间禁止再次确认/取消；成功后关闭，失败时保留弹窗、显示失败标题并允许重试。缓存重开时更新正文与回调，旧异步操作不能关闭新请求。遮罩阻挡点击下层界面，不点击遮罩关闭。

主页底部的“确认弹窗测试”仅在 DEV 环境显示。编队与关卡入口显示对应的阶段占位提示，不假装实现尚未开发的玩法。

## 原包资源与适配边界

已连接项目内 Cocos MCP 扩展（localhost:3000），核实当前项目为 crashfever_replica、Boot 场景无未保存修改，并通过资产刷新和 Prefab 校验导入结果。

使用 `tools/original-assets/inspect-ui-evidence.py` 解码原包 PNG 并按 plist 裁切 atlas 帧，逐块 CRC 校验后由 Pillow 解码验证。原始证据清单在本地 `reverse/original-apk/ui-evidence/manifest.json`，布局说明在同目录 `README.md`。

- 标题页：`NewTitle_Cf2.ccbi` 引用的背景和人物图，等比缩放。原 logo 含日文，因此显示中文标题，未将日文原图直接加入运行界面。
- 加载页：同一原包背景配简体中文加载提示。
- 主界面：原包首页背景片段、页眉、页脚、设置图标；图标的内嵌日文通过节点遮罩隐藏，另显示中文标签。保留当前项目需要的编队、关卡、设置入口。
- 设置/确认弹窗：原包通用底板、标题条、蓝/红按钮，原包 sliderTrack/sliderThumb 和 checkbox/check 图像。动态标题和按钮 Label 不挂 L10nLabel，避免首次 start 覆盖代码文案。

原始文件数值坐标、锚点、动画和完整主页角色舞台尚未恢复，也没有原版运行截图。当前是按原包资源适配 720×1280，不是逐像素复原。标题条九宫格边距是本项目视觉适配值，不是恢复的原始参数。主界面背景片段使用等比覆盖，不拉伸比例。

修改前的 Prefab 与 UI 脚本在本地 `reverse/project-ui-before/`。`build-app-ui.py` 可重建六个 Prefab，但会覆盖手动编辑，后续日常调整优先使用 Cocos 编辑器；运行脚本前先备份。原包资源与按钮/节点命名保留在证据清单中。
