# 确认弹窗与原包界面适配

## 使用确认弹窗

路由已在 `AppEntry` 注册，Prefab 位于 `assets/resources/ui/app/ConfirmDlg.prefab`。

```ts
import type { ConfirmPayload } from './ConfirmDlg';

await UIManager.instance.open<ConfirmPayload>('ConfirmDlg', {
    title: '覆盖存档',
    message: '导入会覆盖现有存档，是否继续？',
    confirmText: '导入',
    cancelText: '取消',
    onConfirm: async () => {
        // 在这里执行操作；若失败请抛出异常。
    },
});
```

`open()` 只表示界面打开完成，不是玩家选择的结果。确认与取消通过各自回调返回。正文自动换行，较长内容限制视口高度并允许纵向滚动。回调执行期间禁止再次确认/取消；成功后关闭，失败时保留弹窗、显示失败标题并允许重试。缓存重开时更新正文与回调，旧异步操作不能关闭新请求。遮罩阻挡点击下层界面，不点击遮罩关闭。

主页临时“确认弹窗测试”入口已删除。编队与关卡入口显示对应的阶段占位提示。
